# Release scope

This public repository distributes model/runtime downloads for Neo, voice, and Rug, plus catalogs, checksums, licenses, and runtime source provenance.

Do not publish the n0is desktop application, app bundles, installers, app ZIP archives, or private application source. Keep desktop application builds local unless the user explicitly requests a desktop app release in a later instruction. A request to publish or update runtime/model downloads does not authorize publishing the desktop app.

Preserve the tested runtime release as the Latest catalog consumed by the local app. Never publish an incomplete manifest or upload user data or credentials.
